# Кузня — веб-проект

Next.js 14 (App Router) + TypeScript + Tailwind CSS + Framer Motion.

Текущий флагманский экран — лендинг книги **«1341 день в изоляции»**
(`/book/1341`). Остальные разделы будущей экосистемы Кузни существуют как
маршруты-заглушки, готовые к наполнению: `/`, `/books`, `/about`, `/forge`,
`/programs`, `/community`, `/articles`, `/contact`.

## Запуск

Собиралось в песочнице без доступа к npm-реестру, поэтому `npm install`
здесь не выполнялся и сборка не проверялась автоматически — код написан
вручную и проверен статически (баланс скобок, резолвинг импортов,
соответствие экспортов). Запустите на своей машине:

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production-сборка
```

## Структура

```
app/                    — маршруты (App Router)
  layout.tsx             — шрифты, Header/Footer, глобальные метаданные
  page.tsx                — главная "Кузня" (заглушка-мост к книге)
  book/1341/page.tsx      — лендинг книги (основной экран)
  books|about|forge|programs|community|articles|contact/
                           — заглушки будущих разделов
components/
  ui/                     — Button, Container, Section — токены дизайна
  layout/                 — Header, Footer, ComingSoon
  motion/                 — FadeIn, RevealText — переиспользуемые анимации
  book/                   — все 14+ секций лендинга книги, включая
                            3D-мокап обложки (BookMockup3D) и
                            scroll-таймлайн чисел (NumberTimeline)
lib/
  content.ts              — весь текст лендинга + факты об авторе,
                             централизованно, с пометками TODO
  site.ts                 — архитектура навигации (единый источник для
                             Header/Footer/sitemap)
```

Ищите `TODO` по всему проекту (`grep -rn "TODO" app lib components`):

   Stripe Payment Link / Gumroad, когда она появится.
2. **Домен.** `kuznya.com` в metadata, `robots.ts`, `sitemap.ts` и
   JSON-LD — заглушка, замените на реальный домен.
3. **Контакты.** Страница `/contact` не содержит канала связи — исходные
   материалы его не называли.
4. **Форматы книги.** Сейчас заявлен только PDF (единственный
   подтверждённый формат). Если появятся EPUB / печать / аудиокнига —
   добавьте их в массив `BOOK.formats` в `lib/content.ts`, вёрстка уже
   рассчитана на несколько бейджей.
5. **Отзывы, СМИ, награды, цифры продаж** — сознательно не добавлены:
   исходные материалы их не подтверждают. Не добавляйте эти блоки без
   верифицированных данных от автора.

## Даты и факты

Все биографические факты и даты (28 апреля 2016 — 29 декабря 2019, 1341
день, 216 страниц, 13 глав, 47 стихотворений) взяты из выходных данных и
предисловия самой книги (`1341_KNIGA_dlya_sayta.pdf`, техзадание для
типографии) — не из брифа, там были расхождения в датах и в написании
названия («в плену» vs «в изоляции»). Печатная версия книги — источник
истины, поэтому лендинг использует её название и её даты.

## Дизайн-система

- Цвета, типографика (Oswald + Lora, те же шрифты, что и в печатной
  книге) и spacing — в `tailwind.config.ts` и `app/globals.css`.
- Акцентный цвет один — `ember` (раскалённый металл/красный), используется
  экономно: цифры, кнопки, кикеры.
- 3D-мокап книги — чистый CSS 3D (без Three.js): вращение по скроллу через
  `useScroll`/`useTransform` из Framer Motion. Three.js сознательно не
  подключался — для одного вращающегося объекта это оправданный минимализм,
  а не экономия на технологиях.
- `prefers-reduced-motion` уважается глобально (`app/globals.css`).
